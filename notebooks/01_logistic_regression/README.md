# Logistic Regression - Reorder Prediction

This folder contains the logistic regression model for reorder 
prediction (will_reorder: 0/1), built on the `customer_product_features` table.

## Data Used
- Source table: `customer_product_features` (BigQuery)
- Target variable: `will_reorder`

## Contents
- `logistic_regression.ipynb`: EDA, preprocessing, model training, and evaluation
